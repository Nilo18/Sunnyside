# Sunnyside Agency Landing Page

This repository contains the solution to the **Sunnyside Agency Landing Page** challenge from Frontend Mentor.  
The project demonstrates a responsive and visually appealing landing page built using **HTML5** and **CSS3**.

---

## Overview

The project is a landing page for a creative agency, focusing on:

- **Responsive Design**: Layout adapts seamlessly across desktop, tablet, and mobile screens.
- **Interactive Elements**: Buttons and links have hover effects for enhanced user experience.
- **Visual Appeal**: Uses vibrant colors, images, and clean layout to align with the brand identity.

---

## Features

- **Responsive Layout** for multiple devices  
- **Hover Effects** for interactive components  
- **Semantic HTML** structure for accessibility  
- **Clean and organized CSS** with reusable classes  

---

## Technologies Used

- **HTML5**: Semantic markup and page structure  
- **CSS3**: Styling, Flexbox/Grid layout, and responsive design
